# Micrositio «Guerrero en el extranjero» — maqueta

Versión estática (solo HTML, CSS, JS e imágenes) del micrositio del IEPC Guerrero, para revisión del diseño.
No tiene backend: no hay PHP ni base de datos, y el chat Catzín muestra su mensaje de error al enviar una pregunta.

## Páginas

| Ruta | Contenido |
| --- | --- |
| `/` y `/guerreroenelextranjero` | Página única en español |
| `/guerreroenelextranjero/en` | Página única en inglés |
| `/guerreroenelextranjero/eventos` | Eventos anteriores (español) |
| `/guerreroenelextranjero/en/eventos` | Eventos anteriores (inglés) |

Los PDFs de normatividad enlazan al sitio oficial (`www.iepcgro.mx/principal`).

## Despliegue

Es un sitio estático: en Vercel se importa el repositorio y se despliega sin configurar nada.
